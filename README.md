# Prompt.OS AI

Prompt.OS AI is a universal AI prompt engineering platform that transforms simple ideas into professional, optimized prompts for multiple AI tools through an intelligent conversational interface.

The platform acts as an AI consultant that understands user requirements, asks follow-up questions when needed, and produces high-quality prompts tailored to specific goals and target AI platforms.

Repository layout

- README.md — project overview and quickstart
- LICENSE — project license (MIT by default)
- .gitignore — common ignores for Node/Next projects
- docs/ — product requirements and architecture docs
- assets/ — logos, icons, and screenshots
- prompts/ — curated prompt templates for each roadmap phase
- design/ — Figma/Zeplin exports and design tokens
- src/ — application source code (Next.js + TypeScript app)
- testing/ — test plans and test suites

Getting started

1. Clone the repository:
   git clone https://github.com/sighalsolutions-sudo/saumya.git
2. Install dependencies (when ready):
   pnpm install
3. Run the development server:
   pnpm dev

Roadmap & phases

See docs/roadmap.md and prompts/ for phase-by-phase details and initial tasks. The project is organized for iterative implementation: Core MVP → Professional Suite → Studio → Enterprise → Marketplace.
