# Prompt.OS AI

Prompt.OS AI is a universal AI prompt engineering platform that transforms simple ideas into professional, optimized prompts for multiple AI tools through an intelligent conversational interface.

Overview

Prompt.OS AI acts as an AI consultant that understands user requirements, asks follow-up questions when needed, and produces high-quality prompts tailored to specific goals and target AI platforms. It supports multiple AI platforms and provides structured prompt modes (Instant, Professional, Enterprise).

Quickstart

Prerequisites

- Node.js 18+
- pnpm (recommended) or npm/yarn

Clone and run

1. git clone https://github.com/sighalsolutions-sudo/saumya.git
2. cd saumya
3. pnpm install
4. pnpm dev
