# ROADMAP

Prompt.OS AI — High level roadmap and milestones

Phase 1 — Core MVP (current focus)
- Landing page (marketing + docs)
- Authentication (Supabase)
- Dashboard & prompt history
- Conversational prompt builder MVP (Instant mode)
- PWA basics (manifest, service worker)

Phase 2 — Professional Prompt Engineering Suite
- Prompt templates & bundles
- Prompt optimizer and testing harness
- Collaboration features (shared collections)

Phase 3 — Prompt.OS AI Studio
- Prompt Doctor (debugging & suggestions)
- Analytics & A/B testing for prompts
- Team workspaces and comments

Phase 4 — Enterprise Platform
- SSO integrations (SAML/OIDC)
- Audit logs & compliance features
- Enterprise SLAs and RBAC

Phase 5 — Marketplace & Ecosystem
- Public API for prompt generation
- Template marketplace and monetization
- Plugin system for third-party connectors

Milestones & Next Steps

- Create GitHub milestones for each phase and open issues for Phase 1 tasks.
- Implement features in feature branches with PRs and CI checks.
- Target initial alpha (internal) release: v0.1.0 — core flows implemented, basic auth, and prompt builder.
