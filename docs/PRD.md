# Product Requirements Document — Prompt.OS AI (Core MVP)

## Purpose
Provide a conversational, multi-mode prompt engineering platform that helps users craft production-ready prompts and choose the best AI tooling for their needs.

## Key features (MVP)
- Responsive landing page
- User authentication (Supabase)
- Dashboard and prompt history
- Conversational prompt builder (Instant / Professional / Enterprise)
- Export options and PWA support

## Users & personas
- Product managers: create briefs and generate prompts for marketing and product ideation
- Developers: generate code-focused prompts and scaffolding
- Creators/Marketers: generate content, scripts, and assets

## Success metrics
- Time-to-first-prompt under 2 minutes for new users
- Prompt conversion rate (user saves or exports) > 20%
- 80%+ of user flows complete without requiring advanced setup
